# 架构说明

## 概述

基于华为云的跨账户私有 API 通信系统，通过 APIG 私有端点实现两个账户之间的安全私有连接。

## 组件说明

### 1. 消费方 (Consumer)

- **FunctionGraph**: 客户端函数，调用私有 API
- **IAM Role**: 角色扮演，获取临时凭证
- **VPC Endpoint**: 私有网络端点

### 2. 提供方 (Provider)

- **APIG**: 私有 API 网关
- **FunctionGraph**: 后端函数，处理业务逻辑
- **GaussDB-Mongo**: 数据存储
- **IAM**: 资源策略控制

## 数据流

1. 消费方通过 IAM 角色获取临时凭证
2. 使用凭证调用 VPC 端点
3. 端点将请求路由到 APIG
4. APIG 验证请求并路由到后端函数
5. 函数读写 GaussDB-Mongo
6. 响应返回消费方
